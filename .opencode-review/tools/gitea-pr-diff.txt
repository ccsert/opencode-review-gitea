Fetch the diff (code changes) for a Gitea/Forgejo pull request.

This tool retrieves file changes in a PR with line numbers for review.

Features:
- Supports file filtering with glob patterns (e.g., "*.ts", "src/**/*.go")
- Two output formats: parsed (with line numbers) or raw (unified diff)

Output formats:
- "parsed" (default): Shows each line with line number prefix for easy reference when creating review comments
- "raw": Returns the raw unified diff format

The parsed format shows:
- [NEW:42] +new line  - Added line at line 42 in new file (use `line: 42` in comments)
- [OLD:38] -old line  - Deleted line at line 38 in old file (use `old_line: 38` in comments)
- [NEW:42]  context   - Unchanged context line (use `line: 42` in comments)

File filtering examples (patterns without "/" match file names at any depth):
- ["*.ts", "*.tsx"] - Only TypeScript files
- ["src/**"] - Only files in src directory

Pages, template and standards:
- Page 1 starts with the Review Template and any Team Review Standards (trusted,
  from configuration and the PR base commit), followed by the untrusted diff.
- Large diffs are split into pages. If the output ends with "Call ... page=N",
  call this tool again with the same arguments and page=N. gitea-review refuses
  a review until every page of this run was read.

When creating review comments with gitea-review tool:
- For [NEW:X] lines → use `line: X`
- For [OLD:X] lines → use `old_line: X`
